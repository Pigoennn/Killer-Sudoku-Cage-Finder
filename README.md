# Killer Sudoku Cage Solver

This simple program generates all the possible combinations to your current cage.

Run the python source file and follow the terminal inputs:

```
Input target (1-45)
Numbers Required  (1-9)
Banned Numbers
```

And the program will output all possible combinations.

An example output is shown below:

```
----- Killer Sudoku Cage Solver -----
Type 'exit', 'quit' to stop

Input target (1-45): 24
Numbers Required (1-9): 4
Banned Numbers (e.g. 1 2 3, or enter none): 7

Found Combinations:
  1. [1, 6, 8, 9]
  2. [2, 5, 8, 9]
  3. [3, 4, 8, 9]
  4. [4, 5, 6, 9]
Required Numbers: 9

-------------------------------------
```

The program will also tell you what numbers are definitely required for the cage.
Have fun!
